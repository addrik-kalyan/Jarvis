# 🤖 Jarvis Assistant

A simple **voice + text based AI assistant** built using Python.
Jarvis can perform tasks like opening apps, searching Google, playing music, and more.

---

## 🚀 Features

* 🎤 Voice recognition (speech input)
* 🔊 Text-to-speech output
* 🌐 Google search
* 📂 Open folders from system
* 🖥️ Open applications (Excel, Word, etc.)
* 🎵 Music player (play, pause, resume, stop)
* 🔊 Volume control
* 🕒 Time and date info
* 💬 Chat history tracking

---

## 📦 Requirements

Install all dependencies using:

```bash
pip install -r requirements.txt
```

Main libraries used:

* pyttsx3
* SpeechRecognition
* pygame
* mutagen

---

## ▶️ How to Run

```bash
python jarvis.py
```
